## Caveats

- Both PDFs are marketing for a paid course; revenue figures in them are unverified claims.
- Some tactics in them conflict with platform rules or are deceptive: dodging "are you AI?", inventing needs (rent, handbag) to get money, and moving fans from one persona to a "new" one. Fanvue requires AI creators to be disclosed as AI. Check current Fanvue terms before using any chat script.
