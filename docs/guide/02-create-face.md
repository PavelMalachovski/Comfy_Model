# 02. Лицо персонажа и датасет

Цель: выбрать одно лицо Греты и получить 20–40 снимков этого лица в разных ракурсах
для обучения LoRA. Нужен работающий под (`uv run cm pod up`).

## 1. Варианты лица

```bash
uv run cm batch face scenes/face.yaml
```

Результат: `out/<дата>-face/<id-сцены>_<NN>.png` (+ `manifest.jsonl`). Шесть сцен по
4 варианта — 24 портрета при разном свете. Повторный запуск пропускает уже
готовые файлы, так что прерванную серию можно просто запустить заново.

Просмотрите все портреты и выберите **один** (максимум два) как эталон.

## 2. Проверка выбранного лица

Лицо должно пройти **все** пункты, иначе выбираем другое:

- [ ] **Явно взрослое** (27–29 лет), без «школьных» и детских черт. Сомневаетесь —
  отбраковывайте.
- [ ] **Не похоже на реального человека.** Загрузите портрет в обратный поиск по
  картинке: Google Lens и Yandex Images. Если выдача содержит кого-то
  узнаваемого (актриса, блогерша, чья-то страница), отбраковывайте.
- [ ] Лицо живое: кожа с порами и веснушками, а не «пластик»; симметрия не
  идеальная; глаза и зубы без артефактов.
- [ ] Выглядит как Грета из `character/bible.md` (светлые пепельно-русые волосы,
  серо-голубые глаза, высокие скулы).

Проверку делаем сейчас, до датасета и LoRA: потом лицо поменять дорого.

## 3. Датасет для LoRA

Запишите путь к выбранному файлу и запустите:

```bash
uv run cm batch dataset scenes/dataset.yaml --ref out/<дата>-face/face-window-light_01.png
```

(подставьте свой путь; Kontext переносит лицо с эталона в новые ракурсы, планы,
одежду и свет). Результат: `out/<дата>-dataset/`.

## 4. Отбраковка вручную

Откройте папку и **удалите файлы**, где:

- лицо «уплыло» (другой человек, чужие черты), слишком гладкое или искажённое;
- сломаны руки, глаза, зубы, очки;
- кадр выглядит несовершеннолетним или «на грани»;
- на фото текст, логотипы или чужие лица.

Лучше 20 хороших снимков, чем 40 с мусором. `cm lora prepare` принимает **15–60**
снимков; вне этого диапазона откажется и скажет, сколько их нашёл. В датасете 40 сцен,
после отбраковки обычно остаётся 20–30.

Выключите под, если дальше не работаете сразу:

```bash
uv run cm pod down
```
