# 04. Ежедневная работа (2–3 часа в день)

## Распорядок

| Что | Сколько | Как часто |
|---|---|---|
| Генерация (запуск пакета, выбор лучших, экспорт) | ~30 мин | раз в 2–3 дня |
| Публикация постов | 30–60 мин | ежедневно |
| Переписка на Fanvue, ответы в комментариях, метрики | остальное время | ежедневно |

Старт (этап 1): 30 фото и 3–5 Reels для Instagram + запас фото для X, Reddit и платного
Telegram. Дальше ориентир ~100–150 отобранных фото в месяц и 8–15 коротких видео
([05](05-video.md)); ритм постинга — в [07. Прогрев](07-warmup.md).

## Цикл генерации (раз в 2–3 дня)

1. Включить под: `uv run cm pod up` (под не включён — `cm batch` скажет «no running pod»).
2. Запустить нужные пакеты. Под занят, пока идёт генерация, поэтому можно запускать
   несколько подряд и уйти заниматься другим.

   ```bash
   uv run cm batch photo scenes/instagram.yaml --lora ohwxroxana_v1.safetensors
   uv run cm batch photo scenes/social.yaml    --lora ohwxroxana_v1.safetensors
   uv run cm batch photo scenes/fanvue.yaml    --lora ohwxroxana_v1.safetensors
   ```

   Какой файл для какой площадки:

   | Файл сцен | Куда | Уровень |
   |---|---|---|
   | `scenes/instagram.yaml` | Instagram (лента, сторис), бесплатный Telegram | роскошь и власть; **без белья, латекса, ступней и фетиш-слов**, без наготы |
   | `scenes/social.yaml` | X, Reddit, платный Telegram | латекс, бельё, корсеты, сапоги, каблуки; без наготы |
   | `scenes/fanvue.yaml` | Fanvue (за подпиской) | то же, интимнее; топлес с пэстис — только на этапе 3 |

3. Выключить под: `uv run cm pod down`.

Каждый файл сцен пишет в свою папку `out/<дата>-<имя файла сцен>/`:
`out/2026-10-20-instagram/`, `out/2026-10-20-social/`, `out/2026-10-20-fanvue/`
(`<id-сцены>_<NN>.png` + `manifest.jsonl`, где у каждой строки есть поле `"tier"`). Так
кадры разных тиров не смешиваются: по имени папки видно, куда их можно публиковать.

Первой строкой `cm batch` печатает папку вывода. Повторный запуск того же пакета в ту
же папку пропускает готовые файлы и не тратит GPU заново. Если пакет прервался и вы
перезапускаете его после полуночи, передайте ту же папку явно:
`--out out/2026-10-20-instagram` (иначе начнётся новая папка с новой датой).

Если ComfyUI не успел за отведённое время (900 с на кадр, 2700 с на видео), пакет
останавливается с сообщением «ComfyUI still busy; re-run later to resume»: под ещё
считает этот кадр. Подождите несколько минут и запустите ту же команду снова.

Каждый файл сцен проверяется целиком **до** постановки в очередь: опечатка, неизвестный
тир или формат, повторный `id` или запрещённое слово отклоняют весь файл с указанием
сцены и причины. Ничего не ставится в очередь, GPU не тратится.

## Выбор лучшего

Просмотрите кадры и оставьте лучшие. Критерии: узнаваемое лицо, живая кожа,
правильные руки и пальцы, нет артефактов фона, подходит под уровень площадки. Остальное
не публикуйте. Лишние файлы можно просто удалить.

## Экспорт перед публикацией

Выбранные файлы публикуйте **только** после экспорта:

```bash
uv run cm export out/2026-10-20-instagram/penthouse-skyline-gown_01.png
```

`cm export` кладёт JPEG в `export/`, записывает в EXIF пометку «AI-generated»,
**удаляет метаданные промпта** (ComfyUI иначе кладёт в PNG весь промпт и граф) и
добавляет лёгкое плёночное зерно (`--grain 0` отключает, `--to` меняет папку).
Можно сразу несколько файлов:

```bash
uv run cm export out/2026-10-20-instagram/*_01.png
```

Метаданные не заменяют видимую пометку ИИ в профиле и подписи, см. [06](06-launch.md).

## Свои сцены

Скопируйте любой файл из `scenes/` (например, `scenes/my.yaml`) и добавьте сцену:

```yaml
scenes:
  - id: rooftop-sunset-power
    prompt: >-
      standing on a rooftop terrace at sunset, tailored white suit,
      warm side light, camera slightly below eye level
```

Правила:

- В промпте только место, одежда, поза, свет и камера: описание лица и стиль
  добавляются автоматически из `character/profile.yaml`.
- `id` уникален в файле; `tier` (`instagram` | `social` | `fanvue`) определяет допустимое;
  `aspect` — `4:5` (лента), `9:16` (сторис/рилс) или `1:1`, `count` — число вариантов (от 1 до 16).
- Запрещённые слова и намёки на несовершеннолетних или наготу отклоняются проверкой
  безопасности (в том числе `sheer`, `see-through`, `transparent`, `undressed`, `baby face`
  на любом тире). Не обходите её.
- Текст постов (подписи) пишется по-английски в голосе Роксаны, см. `character/bible.md`.
