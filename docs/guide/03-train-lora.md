# 03. Обучение LoRA

Цель: получить файл `ohwxgreta_v1.safetensors`, после которого лицо Греты одно и то же
во всех кадрах. Разовая операция (~2 ч, ≈ $1–2).

## Перед стартом

- В `.env` есть `HF_TOKEN`, лицензия FLUX.1-dev принята на huggingface.co (см.
  [01](01-setup.md)). Если токена не было при создании пода: `cm pod down && cm pod up`.
- Датасет отбракован руками (см. [02](02-create-face.md)).

## 1. Подготовка датасета

```bash
uv run cm lora prepare out/<дата>-dataset
```

Команда нумерует оставшиеся картинки и пишет подписи в `dataset/ohwxgreta/`.
`ohwxgreta` — триггер-слово LoRA.

## 2. Свежий под и запуск обучения

`cm lora train` **отказывается работать на поде старше 1 часа** (сторож выключает под
через 4 часа, а обучение идёт до ~3 ч). Поэтому:

```bash
uv run cm pod down && uv run cm pod up
uv run cm lora train
```

(`--force` обходит проверку возраста; делайте это, только если понимаете, что
уложитесь в остаток до 4 часов.) Обучение идёт **в фоне на поде**, терминал можно
закрыть. Под при этом остаётся включённым.

## 3. Следить за ходом

```bash
uv run cm lora status
```

Показывает последние 40 строк лога и идёт ли ещё обучение. Заглядывайте раз в
20–30 минут.

Готовый файл: `/workspace/ComfyUI/models/loras/ohwxgreta_v1.safetensors`. После
этого можно сразу генерировать фото (см. [04](04-daily.md)), пока под жив.

## 4. Как оценить результат

Сделайте пробную серию и посмотрите 20–30 кадров:

```bash
uv run cm batch photo scenes/instagram.yaml --lora ohwxgreta_v1.safetensors
```

Хорошо, если:

- узнаётся одно и то же лицо в разных ракурсах, свете и одежде;
- кожа живая, без «пластика»;
- оно не «залипло» в одну позу и один фон.

Плохо, если лицо плывёт (недообучение) или все кадры копируют снимки датасета, а
промпт игнорируется (переобучение). Тогда:

- слабее/сильнее влияние при генерации: `--strength 0.7` или `--strength 1.0`
  (по умолчанию `0.9`);
- иначе улучшите датасет (больше разнообразия, меньше мусора) и переобучите как
  новую версию на свежем поде:

```bash
uv run cm pod down && uv run cm pod up
uv run cm lora train --version 2
```

Результат: `ohwxgreta_v2.safetensors`, v1 остаётся рядом. После этого в `--lora`
укажите новую версию.

После обучения выключите под: `uv run cm pod down`.
