# 11. Как мы теперь рендерим: Mac + RunPod

С 14 ноября 2026 фото делаются на Маке бесплатно, а RunPod нужен только для тяжёлых
задач. Пошаговые команды ниже; запускать их может Claude, вы смотрите результат.

## Кто что делает

| Задача | Где | Время | Цена |
|---|---|---|---|
| Фото по плану (Qwen 2512 + LoRA v4, быстрый режим) | Mac | ~11 мин на кадр, ~40 за ночь | $0 |
| Финальная обработка «под телефон» | Mac | секунды | $0 |
| Отбор кадров, сторис, подписи | вы | — | $0 |
| Повышение резкости SeedVR2 (по желанию, для лучших кадров) | RunPod | ~1 мин на кадр | ~$1.4 в час |
| Замена фона на её комнату (`rooms/`) | RunPod | ~1 мин на кадр | ~$1.4 в час |
| Видео для Reels (Wan 2.2) | RunPod | минуты на ролик | ~$1.4 в час |
| Новая версия LoRA | RunPod | ~1.5 часа | ~$2 |

Цена RunPod — RTX 5090 по факту счетов, включая диск пода. Сетевой диск `bakeoff-no`
(200 ГБ, модели и LoRA) стоит ещё ~$0.47 в день, даже когда поды выключены.

## 1. Фото на Маке

### Включить и выключить ComfyUI

```bash
scripts/mac_comfy.sh start
```

Откроется окно в браузере: `http://127.0.0.1:8188`. Пока ComfyUI включён, он держит
15–20 ГБ памяти; после рендера выключайте:

```bash
scripts/mac_comfy.sh stop
```

### Пачка кадров по файлу сцен

```bash
CM_WAIT_TIMEOUT_S=3600 .venv/bin/cm batch photo scenes/plan50_instagram.yaml \
  --profile character/profile_phone.yaml --lora ohwxroxana_v4.safetensors --strength 0.8 \
  --workflows workflows/qwen-mac-fast --out out/dev/plan50-ig --url http://127.0.0.1:8188
```

- `CM_WAIT_TIMEOUT_S=3600` — ждать кадр до часа (на Маке он идёт ~11 минут, а `cm`
  по умолчанию ждёт 15).
- Прерванную пачку можно перезапустить той же командой: готовые кадры пропускаются.
- Ночью: держите Мак на зарядке и не давайте ему уснуть (Настройки → Аккумулятор →
  «Не переходить в режим сна при питании от сети», или `caffeinate -dis` в терминале).
  Крышку не закрывайте.

### Обработка «под телефон»

```bash
.venv/bin/python scripts/phone_finish.py out/dev/plan50-ig out/dev/plan50-ig-final --hdr 0.5
```

Готовые JPEG — в `out/dev/plan50-ig-final`. Отбор: смотрите каждый кадр на 100%
(руки, пальцы, лицо, телефон в обычном селфи). Брак переносите в `rejected/`, не удаляйте.

### Что в быстром режиме

Граф `workflows/qwen-mac-fast/photo.json`: Qwen-Image 2512 в сжатом виде (GGUF Q5_K_M),
LoRA Lightning (8 шагов вместо 50), потом увеличение в 1.5 раза (4 шага) и доработка
лица (6 шагов). На 100% кожа не хуже облачной. Полный облачный рецепт на Маке идёт
1.5–2 часа на кадр — его не используем.

### Режим hero-opt (лучшие кадры)

Граф `workflows/qwen-mac-hero-opt/photo.json`: полная модель без Lightning, cfg 4,
35 / 14 / 14 шагов, детейлер лица и рук. С 17 ноября 2026 в него встроен **EasyCache 0.2**
(узел 33): кадр идёт ~40–45 минут вместо 85–105, картинка почти та же (тест в
`out/dev/sheets-v4check/easycache.jpg`). `workflows/qwen-mac-hero-opt-v5` — то же плюс негатив
«селфи, рука к камере, лишние руки» для кадров «снимает подруга». Порядок работы: быстрый
режим для перебора, лучший кадр — в hero-opt с тем же seed, мелочи — Qwen-Edit
(`workflows/qwen-mac-edit`).

С 17 ноября 2026 для hero-opt основной набор: LoRA `ohwxroxana_v5.safetensors` 0.8, профиль
`character/profile_phone_40.yaml` и граф `workflows/qwen-mac-hero-opt-v5-40` (негатив против
«старит» и «кукольное лицо»). С `profile_phone.yaml` в hero-opt она выглядит на 50, с
`profile_phone_young.yaml` — на 33. Кадры «подруга снимает в полный рост» — только со скелетом
ControlNet: LoRA v5 без него уходит в селфи.

```bash
CM_WAIT_TIMEOUT_S=36000 .venv/bin/cm batch photo scenes/<файл>.yaml \
  --profile character/profile_phone_40.yaml --lora ohwxroxana_v5.safetensors --strength 0.8 \
  --workflows workflows/qwen-mac-hero-opt-v5-40 --out out/dev/<папка> --url http://127.0.0.1:8188
```

### Норма: 7–8 кадров в hero-opt в день

С 18 ноября 2026 на один день контента рендерим 7–8 кадров в hero-opt (5–6 часов Мака,
брак около трети):

| Куда | Кадров | Что публикуем |
|---|---|---|
| Instagram, карусель в одной локации | 3 | лучшие 2–3 |
| X | 1 | 1 |
| Telegram | 1 | 1 (2 раза в неделю — отдельная съёмка, иначе запасной кадр из карусели) |
| Fanvue | 2 | сет; только Мак, запускает оператор |

Сторис — из запасных кадров и быстрого режима.

Готовые к публикации файлы лежат в `out/prod/dayN/`: `p01a.jpg` (Instagram, буквы — порядок
в карусели), `x01.jpg` (X), `t01.jpg` (Telegram), `f01a.jpg` (Fanvue), `s01a.jpg` (сторис),
число — номер дня. Какой рендер идёт в какой файл — в `scenes/prod_days.yaml`; собирает
`.venv/bin/python scripts/prod_pack.py` (обработка «под телефон» уже внутри, исходники не трогает). За ночь Мак делает 10–12 кадров, то есть
неделя контента — это около 4–5 ночей или 3 ночи плюс дневные пачки.

## 2. Облако (RunPod): только пачками

Копите задачи и делайте их за один запуск пода — каждый запуск тратит ~5–10 минут
на старт. Под выключается сам после команд (`scripts/pod_session.sh`), сторож — через
15 минут простоя.

```bash
CM_CAPACITY_TRIES=240 scripts/pod_session.sh \
  ".venv/bin/cm lora refine out/dev/plan50-ig-picked --out out/dev/plan50-ig-seedvr --graph workflows/qwen/seedvr.json"
```

- **SeedVR2** (`workflows/qwen/seedvr.json`) — по желанию, только для отобранных
  кадров: Мак уже даёт живую кожу, SeedVR2 добавляет резкости при сильном зуме.
- **Замена фона** на её комнату:
  `cm lora refine <папка> --graph workflows/qwen/room.json --room rooms/bedroom.png`.
  Модель иногда сдвигает фигуру — отбирайте.
- Перед запуском проверьте баланс RunPod (сейчас ~$3.4).

## 3. Видео для Reels (позже, на RunPod)

Готовый граф `workflows/video.json` и сцены `scenes/video.yaml` — от прежнего проекта:
Wan 2.2 TI2V 5B, ~5 секунд из одного фото, промпт описывает только движение
(«she turns her head and smiles», «hair moves in the wind»). Подробно — [05](05-video.md).

Что нужно доделать перед первыми Reels (это отдельная задача):

1. Добавить модели Wan на диск `bakeoff-no` — сейчас их там нет (они в
   `pod/models.yaml`, а пода с Qwen использует `pod/qwen_models.yaml`). Для живого
   лица лучше Wan 2.2 I2V 14B (fp8, помещается в 5090), 5B — быстрее и дешевле.
2. Пробный прогон 3–5 роликов из лучших фото плана: держится ли лицо Роксаны в
   движении. Если «плывёт» — короче ролик (3 сек) или меньше движения.
3. GIF для сторис делается из готового ролика локально (`ffmpeg`), без облака.
4. Экспорт только через `cm export`: он убирает метаданные и ставит тег AI-generated.

Ориентир: одна сессия на 10–15 роликов — около часа пода.
