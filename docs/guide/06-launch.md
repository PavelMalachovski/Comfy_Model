# 06. Чек-лист запуска площадок

Правила площадок меняются. **Перед запуском заново прочитайте актуальные правила
Fanvue, Instagram, Reddit, X и Telegram** и правила каждого сабреддита. Ниже —
то, что заложено в проект, и выводы из исследования 2026-11-07 (см. спецификацию).
План прогрева по неделям — в [07](07-warmup.md).

Общее для всех площадок:

- Аккаунты регистрирует и верифицирует **оператор на себя**. Публично — только имя
  персонажа (Roxana / Roxy), никаких личных данных оператора.
- Пометка ИИ везде: в профиле и там, где площадка даёт встроенную метку. Шаблоны
  bio для каждой площадки — в `character/bible.md` (раздел «Шаблоны bio»).
- Роксана не называет себя живой женщиной. На прямой вопрос — честно: ИИ-персонаж.
- Публикуем только файлы из `cm export` (см. [04](04-daily.md)).
- Нагота запрещена на всех площадках в этапе 1. Топлес с пэстис появится на этапе 3
  и только на Fanvue за плату.
- Публично Роксана не нападает на мужчин как на группу — только превосходство и
  насмешка. Жёсткая ролевая игра — за пэйволлом.

## Перед первым постом

- [ ] LoRA обучена, лицо проверено (см. [02](02-create-face.md), [03](03-train-lora.md)).
- [ ] 30 отобранных и экспортированных фото для Instagram + 3–5 Reels ([05](05-video.md)).
- [ ] 10–15 фото из `scenes/social.yaml` в запасе для X, Reddit и Telegram.
- [ ] Хэндлы выбраны и одинаковые на всех площадках, где возможно.
- [ ] Почта, пароли, 2FA на всех аккаунтах.

## Instagram

Роль: витрина «властной роскошной женщины». **Главный риск бана — «скрытое
предложение секс-услуг»:** ссылка на платный канал вместе с сексуальным намёком
(поза, эмодзи, сленг) считается нарушением.

- [ ] Профессиональный аккаунт (creator), bio из библии с пометкой ИИ
  `AI-generated persona`; включайте встроенную метку ИИ на каждом посте.
- [ ] Только файлы тира `instagram`: без белья, латекса, крупных ступней.
- [ ] В подписях и хэштегах нет слов slave, mistress, femdom, fetish.
- [ ] Ссылку в bio ставьте на бесплатный Telegram-канал, а не на Fanvue.
- [ ] Ритм: 4–5 Reels в неделю + сторис ежедневно (подробнее в [07](07-warmup.md)).

## X

Роль: главный прогрев ниши. Взрослый контент разрешён, ИИ-контент тоже — с пометкой.

- [ ] Bio из библии с пометкой ИИ; аватар и шапка — без откровенного.
- [ ] Медиа тира `social` помечайте как «sensitive content» (настройка аккаунта и поста).
- [ ] Ежедневно: 1–3 поста, приказы и опросы в голосе Роксаны, ссылка на бесплатный
  Telegram в закрепе (Fanvue — с месяца 4).

## Reddit

Роль: трафик из нишевых сабреддитов. Откровенный ИИ-контент с вымышленными людьми
Reddit допускает с меткой NSFW, но **каждый сабреддит решает сам**.

- [ ] В профиле пометка ИИ из библии.
- [ ] Для каждого сабреддита прочитаны правила: разрешён ли ИИ-контент и как его
  помечать. Если запрещён — не публикуйте.
- [ ] Метка NSFW на откровенных постах. Сначала комментарии и активность, потом посты.

## Telegram

Два канала:

- **Бесплатный** (с первого дня): тизеры, «приказ дня», анонсы; уровень `instagram`;
  в описании пометка ИИ из библии.
- **Платный** (с месяца 4): встроенная платная подписка канала за Telegram Stars,
  уровень `social` (латекс, бельё), **без топлеса**.

- [ ] Описание обоих каналов с пометкой ИИ `AI-generated persona`.
- [ ] Учтите: на iPhone каналы 18+ по умолчанию скрыты — часть аудитории не увидит
  платный канал, пока сама не отключит фильтр (через веб или десктоп).
- [ ] Вывод Stars: через Fragment в TON, не раньше чем через 21 день после
  получения; нужен TON-кошелёк. Курс и комиссии сверяйте на Fragment.
- [ ] Файлы тира `fanvue` в Telegram не выкладываем.

## Fanvue

Основной заработок (с месяца 4): подписка ~$10–14, платные сообщения (PPV),
персональные заказы, чаевые. Комиссия 20% (иногда промо 15% в первые месяцы —
проверьте), при выводе ещё ~1%.

- [ ] Верификация личности — **оператор на себя**.
- [ ] Аккаунт помечен как ИИ (AI creator), пометка ИИ в bio из библии.
- [ ] **Публичная часть строго SFW:** аватар, баннер, видео-приветствие и описание
  без наготы, «намёка на наготу», просвечивающей одежды и откровенных поз — берите
  фото тира `instagram`.
- [ ] Откровенное — только за подпиской или в PPV.
- [ ] Переписка: черновики готовит ИИ (этап 4), оператор правит и отправляет. Правила
  переписки — в библии.
- [ ] Выплаты на банковский счёт в ЕС, налоговые данные заполнены.

## Юридическое

- [ ] **EU AI Act**: пометка ИИ-контента требуется обязательствами по прозрачности;
  пометка в профилях — необходимое, но не гарантия соответствия. Проверьте
  актуальный текст закона, при необходимости — юрист.
- [ ] Доход декларируется по законам вашей страны (самозанятость/ИП) — узнайте у
  бухгалтера до первых выплат.
- [ ] Персонаж вымышленный, взрослый (около 40), ни на кого не похож.
