# 08. Сравнение моделей (bake-off)

Цель: увидеть при 100% увеличении, какая модель со свободной лицензией даёт самые живые
снимки, и выбрать её для лица, датасета и LoRA. Эти картинки только для оценки: они не
публикуются и не идут в датасет. Модели FLUX в сравнении не участвуют (см. спек
`docs/superpowers/specs/2026-11-08-roxana-photoreal-bakeoff-design.md`).

Модели: Qwen-Image 2512, Z-Image, Z-Image Turbo, HiDream-O1. Всего 24 кадра.
Ожидаемая цена: **$3–5** за работу пода (сверьте цену RTX 4090 в консоли RunPod) плюс
временный том. Оплата идёт, пока под включён.

## 1. Временный том

1. RunPod → Storage → **New Network Volume**: датацентр **EU-RO-1**, размер **150 GB**.
2. В `.env` запишите его ID в `RUNPOD_VOLUME_ID`. Прежнее значение сохраните, если том
   уже есть.

## 2. Поднять под только с моделями сравнения

```bash
uv run cm pod up --models pod/bakeoff_models.yaml
```

Первый запуск скачивает около 80 ГБ моделей.

## 3. Пробный кадр от каждой модели

```bash
uv run cm bakeoff run --limit 1
```

Откройте `out/bakeoff/<модель>/`: должно быть 4 осмысленных кадра. Если что-то не так,
остановитесь и разберитесь до полного прогона, иначе заплатите за брак.

## 4. Полный прогон

```bash
uv run cm bakeoff run
```

Готовые кадры повторно не считаются. Сторож выключает под через 4 часа; если это случилось
раньше конца, снова выполните шаг 2 и эту команду.

## 5. Выключить под

```bash
uv run cm pod down
uv run cm pod status
```

## 6. Выбор вслепую

```bash
uv run cm bakeoff sheets --out out/bakeoff
```

В `out/bakeoff/sheets/` на каждую сцену по два файла: `<сцена>.jpg` (кадры) и
`<сцена>_faces.jpg` (лица в исходном размере). Столбцы подписаны буквами. Смотрите по
порядку: живая кожа, возраст около 40, руки, ощущение настоящего снимка, латекс и ракурс с
пола, узнаваемость Дубая. Сначала назовите букву и только потом открывайте
`out/bakeoff/key.json`.

## 7. Удалить временный том

Перед этим убедитесь, что под выключен. RunPod → Storage → удалите том на 150 GB и верните
прежний `RUNPOD_VOLUME_ID` в `.env`.

Дальше: лицо, датасет и LoRA на выбранной модели по отдельному плану.
