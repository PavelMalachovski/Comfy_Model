# 05. Короткие видео из фото

Видео (image-to-video, ~5 секунд) оживляет готовый кадр. Генерируется пакетом, пока вы
заняты другим. Нужны **экспортированные** вертикальные фото 9:16.

## 1. Подготовьте картинки

Записи `image:` в `scenes/video.yaml` **это заглушки** (`../export/dunes-wind.jpg` и
т. п.). Замените их путями к своим фото:

1. Сгенерируйте кадры в формате `9:16` (в сцене укажите `aspect: "9:16"`) и выберите лучшие.
2. Экспортируйте: `uv run cm export out/<дата>-photo/<сцена>_01.png`. Файлы появятся в `export/`.
3. В `scenes/video.yaml` у каждой сцены поставьте `image: ../export/<ваш-файл>.jpg`
   (пути относительно папки `scenes/`; файл должен существовать в момент запуска).
4. В `prompt` описывайте **только движение** (ветер, поворот головы, шаг): промпт
   используется дословно. Лицо и одежду не описывайте.

## 2. Запуск

```bash
uv run cm pod up
uv run cm batch video scenes/video.yaml
uv run cm pod down
```

Результат: `out/<дата>-video/<сцена>_<NN>.mp4` (+ `manifest.jsonl`). `cm export`
перепаковывает видео через `ffmpeg` без перекодирования: удаляет все метаданные (в том
числе промпт и граф ComfyUI) и ставит тег `comment=AI-generated`. Если `ffmpeg` не
установлен, файл копируется как есть и печатается предупреждение: такое видео **не
публикуйте**, сначала установите `ffmpeg` и повторите экспорт.

```bash
uv run cm export out/<дата>-video/hair-in-wind-dunes_01.mp4
```

Видео идёт дольше фото: запускайте пакет и уходите, а `cm pod down` выполните после
завершения (или полагайтесь на сторожа: 15 мин простоя). Прерванный пакет безопасно
перезапустить: готовые файлы пропускаются.

## Куда публиковать

Instagram Reels и сторис (только безопасный контент), X, Telegram (только ролики из кадров тира `instagram`). Для Fanvue
подходит тот же ролик. Перед публикацией поставьте пометку ИИ на каждой площадке (см.
[06](06-launch.md)). Ориентир: 8–15 роликов в месяц.
