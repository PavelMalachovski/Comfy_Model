# 01. Установка и первый запуск пода

Цель: аккаунты, ключи, `.env`, первый `cm pod up` / `cm pod down`. Займёт 1–2 часа
(большая часть — ожидание первой загрузки моделей).

## Что понадобится на своей машине

`uv`, `git`, `ssh`, `rsync`, `ffmpeg` (нужен `cm export` для видео: без него метаданные
промпта из .mp4 не удаляются), браузер. Репозиторий уже склонирован; все команды ниже
выполняются **из корня репозитория**.

## 1. RunPod

1. Зарегистрируйтесь на runpod.io, пополните баланс на **$10** (для старта хватит).
   Оплата картой ЕС.
2. Settings → **API Keys** → создайте ключ (Read & Write). Сохраните его: значение
   пойдёт в `RUNPOD_API_KEY`.
3. Settings → **SSH Public Keys**: добавьте свой публичный ключ. Если ключа нет:

   ```bash
   ssh-keygen -t ed25519 -C "runpod"
   cat ~/.ssh/id_ed25519.pub
   ```

4. Storage → **New Network Volume**: датацентр **EU-RO-1** (как в
   `config/settings.yaml`), размер **100 GB**. Скопируйте ID тома (`RUNPOD_VOLUME_ID`).
   Том должен быть именно в том датацентре, который указан в `datacenter`.

## 2. Hugging Face

1. Создайте аккаунт на huggingface.co.
2. Откройте страницу `black-forest-labs/FLUX.1-dev` и **примите лицензию** (модель
   gated: без этого скачивание и обучение LoRA не работают).
3. Settings → Access Tokens → создайте токен типа **Read** (`HF_TOKEN`).

## 3. `.env` и зависимости

```bash
cp .env.example .env
$EDITOR .env      # RUNPOD_API_KEY, RUNPOD_VOLUME_ID, HF_TOKEN
uv sync
```

> **`HF_TOKEN` должен быть в `.env` ДО `cm pod up`.** Токен передаётся поду при
> создании. Если добавили его позже — `cm pod down && cm pod up`.

`.env` в git не попадает. Никому не показывайте его содержимое.

## 4. Проверка ссылок на модели (один раз, со своей машины)

Перед первым подом один раз проверьте у себя, что ссылки на скачивание моделей живы:

```bash
uv run python -m comfy_model.workflow --check-urls
```

Если какая-то ссылка не отвечает — не запускайте под, сообщите об ошибке: иначе
первая загрузка упадёт после того, как вы уже заплатите за GPU.

## 5. Первый запуск

```bash
uv run cm pod up
```

- Первый запуск качает **~40 GB моделей** на сетевой том. Это долго (десятки минут,
  зависит от канала пода). Последующие запуски быстрые: модели уже на томе.
- Команда сама синхронизирует файлы, ставит ComfyUI и **сторожа (watchdog)**.
  Если `cm pod up` падает, она сама завершает под (смотрите сообщение об ошибке).
- В конце печатается адрес ComfyUI. Откройте его в браузере: интерфейс должен
  загрузиться. Руками в нём работать не нужно, всё делает `cm batch`.

Полезно:

```bash
uv run cm pod status    # жив ли под, адрес ComfyUI
uv run cm pod ssh       # shell на поде
```

**Сторож выключает под** через 15 минут простоя или через 4 часа после старта, что
бы ни случилось. Но привычка простая: закончили работу, сразу выключайте.

```bash
uv run cm pod down
```

Если под уже выключился сам, `cm pod status` и `cm batch` скажут
«no running pod — run `cm pod up`» и очистят устаревшее состояние.

## Стоимость (ориентировочно, проверьте актуальные цены)

| Статья | Цена |
|---|---|
| Аренда GPU RTX 4090, ~80–100 ч (потолок, не план) | ~$35–45 |
| Сетевой том 100 GB | ~$5–10 |
| Обучение LoRA (разово, ~2 ч) | ~$1–2 |
| Площадки | $0 (Fanvue берёт % с продаж) |
| **Итого** | **~$45–60 в месяц** |

Цена GPU — ≈ $0.3–0.7 в час, поэтому главное правило: **не оставляйте под включённым**.
